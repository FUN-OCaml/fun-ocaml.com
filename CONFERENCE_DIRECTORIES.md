## Submission Checklist

For each directory submission, prepare:

- [ ] Conference name: FUN OCaml 2025
- [ ] Dates: September 15-16, 2025
- [ ] Location: Digital Knowledge Village, Warsaw, Poland
- [ ] Website: https://fun-ocaml.com
- [ ] Short description (50 words)
- [ ] Long description (200 words)
- [ ] Logo (various sizes)
- [ ] Social media preview image
- [ ] Tags: OCaml, functional programming, open source, workshops, conference
- [ ] CFP dates (if applicable)
- [ ] Registration link
- [ ] Price: Free

## Follow-up Actions

1. Monitor for approval/publication

3. Add to conference website footer: "Listed on..."
4. Track referral traffic in analytics
5. Build relationships with directory maintainers
